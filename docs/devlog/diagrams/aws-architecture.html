1. 1사용자가 도메인을 Route 53에서 찾는다.
  2. 2HTTPS로 EC2의 Nginx에 들어온다. 화면 파일(React)은 Nginx가 바로 준다.
  3. 3/api/* 요청만 Spring Boot로 넘긴다.
  4. 4Spring Security가 JWT를 확인하고, 그 기관의 ACTIVE 멤버인지 · 모듈이 켜져 있는지 · 역할이 맞는지 본다.
  5. 5업무 데이터는 프라이빗 서브넷의 RDS. 예약 겹침은 EXCLUDE 제약, 금액은 CHECK로 DB가 지킨다.
  6. 6로고 같은 파일은 S3. 키 대신 EC2의 IAM 역할로 접근하고, DB에는 파일 키만 둔다.
  7. 7구글 로그인: 인가 코드를 교환하고 ID 토큰을 검증한다(트랜잭션 밖, 타임아웃 5초).
  8. 8GitHub Actions가 테스트 → 이미지 빌드 → 블루그린 배포를 한다.
  9. 9운영자는 SSH 대신 SSM Session Manager로 들어간다. 예산은 AWS Budgets로 알린다.
아이콘: AWS Architecture Icons, Simple Icons. 지금은 로컬 Docker Compose로 같은 구성(EC2 대신 내 컴퓨터, RDS 대신 PostgreSQL 컨테이너, S3 대신 SeaweedFS)을 띄운다.
